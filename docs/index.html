Installer developer’s guide & video ↗

  1. Prepare your phone.

    Install Wear Installer 2 and download the Edge Forecast APK. Connect phone and watch to the same trusted Wi-Fi network. Installing this APK on the phone itself will not install the watch face.

  2. Enable debugging on the watch.

    On Galaxy Watch: Settings → About watch → Software information. Tap Software version repeatedly until Developer options are enabled. On other watches, find Build number under System → About → Versions.

    Return to Settings → Developer options. Turn on ADB debugging, then Wireless debugging. Allow your trusted network; keep this screen open.

  3. Pair Wear Installer 2.

    Enter the watch’s IP address on the installer’s home screen and tap Done. Open its menu → Pair with watch → Enable. On the watch, tap Pair new device.

    In the installer’s pairing dialog, enter the six-digit pairing code, a space, then the pairing port. Tap Done and wait for pairing success. Keep codes private.

  4. Use the connection port.

    Return to the watch’s main Wireless debugging screen. Enter the port shown after its IP address into Wear Installer 2’s home screen. This is the connection port—not the pairing port. It can change when debugging restarts.

  5. Send the APK to your watch.

    In Wear Installer 2, choose Custom APK, select edge-forecast-1.5.24.apk from Downloads, then tap Install. Wait for success. Updates install over the existing face; do not uninstall first.

  6. Select the face & finish.

    Long-press your current watch face, open the face picker / Add watch face, and choose Edge Forecast. Customize on the watch. Turn off Wireless debugging and ADB debugging when finished.

  7. Add phone battery (optional).

    Install and open Phone Battery Complication on both your Android phone and Wear OS watch. In Edge Forecast’s editor, choose Phone Battery for the phone-battery slot, then save. Tap the value to request an update while connected.

    Existing app setup needs no reinstall. If an update cleared the slot, select the provider again. Without it, leave the slot at None / Empty; the watch-only layout is still a preview.

HELP

A few answers.

Why might weather or phone battery be missing?

Weather needs the watch’s weather service and permissions. Phone battery needs the companion setup above. Tapping weather targets Samsung Weather, which must be installed.

Updates or issues?

Updates are manual downloads from this page. Report an issue on GitHub with your watch model and software version. Don’t include pairing codes or private details.

Does this page track me?

GitHub provides the download count and may log visits and download requests. No additional analytics or ad service is used; see its privacy policy. Watch services and companion apps have their own policies.
